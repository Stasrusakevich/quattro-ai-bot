# Quattro AI

Внутренний AI Assistant для сотрудников Quattro Space.

## Цель проекта
Создать AI-инструмент, который помогает команде:
- отвечать клиентам;
- работать с заявками;
- использовать базу знаний;
- контролировать задачи;
- анализировать переписки и звонки.

## Статус
Проект в разработке.
