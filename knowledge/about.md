# Quattro Space

Quattro Space — event-площадка для проведения мероприятий.

## Основные направления
- корпоративные мероприятия
- банкеты
- презентации
- деловые события
- частные мероприятия
- съемки
  ## Что нужно уточнить у Стаса
- точное описание площадки
- адрес
- вместимость
- какие залы/зоны есть
- ключевые преимущества
